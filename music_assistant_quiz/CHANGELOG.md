# Changelog

## 2.11.0.dev5

- Title Reveal: the guess field is cleared when the next song starts.
- Title Reveal: emoji are removed from song titles. Before, a title like "Fire 🔥"
  rejected the correct guess "Fire".

## 2.11.0.dev4

- German texts for Title Reveal (test builds only, see the repository README).

## 2.11.0.dev3

- Title Reveal: +200 points for the first correct guess.
- Title Reveal: optional artist bonus (enable it in the game setup). After guessing the
  title, players get one try at the artist for +250 points, or can skip it.

## 2.11.0.dev2

- Add the `spotify_client_id` and `app_vars` options to supply your own provider
  credentials, since this test build has none bundled.

## 2.11.0.dev1

- First test build with the Music Quiz "Title Reveal" game.
